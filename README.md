# Лабораторная работа №2: ETL-пайплайн на Apache Spark

## Описание
В данной работе реализован автоматизированный процесс обработки данных (ETL) с использованием Apache Spark. Данные трансформируются из реляционной модели (PostgreSQL) в аналитические витрины NoSQL хранилища (ClickHouse).

## Архитектура
* **Source:** PostgreSQL (Слой сырых данных `raw_data_import`).
* **Processing:** Apache Spark (Трансформация в "Снежинку" и расчет витрин).
* **Target:** ClickHouse (6 аналитических витрин в базе `reports_db`).

## Инструкция по запуску

### 1. Подготовка инфраструктуры
Запустите все сервисы через Docker:
```bash
docker compose up -d
```

![alt text](image.png)

После запуска необходимо создать базу данных в ClickHouse:
```bash
docker exec -it lab2_clickhouse clickhouse-client --query "CREATE DATABASE IF NOT EXISTS reports_db"
```

### 2. Запуск ETL процесса
1. **Подготовка данных в PostgreSQL:**
   - С помощью DBeaver выполните скрипт `ddl.sql` для создания структуры таблиц.
   - Импортируйте все 10 файлов `MOCK_DATA.csv` из папки `data/` в таблицу `raw_data_import`.

2. **Работа с Apache Spark (Jupyter Notebook):**
   - Перейдите в браузере по адресу `http://localhost:8888`.
   - Откройте файл `spark_etl_lab2.ipynb`.
   - Запустите код.

**В ходе выполнения скрипта Spark выполнит следующие задачи:**
*   Очистит и нормализует данные из "широкой" таблицы.
*   Заполнит модель данных "Снежинка" в PostgreSQL (справочники и таблицу фактов).
*   Выполнит агрегацию данных для создания аналитических витрин.
*   Запишет готовые отчеты в базу данных ClickHouse.

## Описание созданных отчетов в ClickHouse

В базе данных `reports_db` (ClickHouse) сформированы следующие витрины:
1.  **report_1_products** — Анализ выручки, количества продаж и популярности продуктов.
2.  **report_2_customers** — Анализ поведения клиентов (Топ-10 по сумме покупок и средний чек).
3.  **report_3_time** — Анализ сезонности: месячные и годовые тренды продаж.
4.  **report_4_stores** — Анализ эффективности магазинов: выручка и распределение по городам.
5.  **report_5_suppliers** — Анализ эффективности поставщиков и средней цены их товаров.
6.  **report_6_quality** — Анализ качества продукции на основе средних рейтингов и количества отзывов.
